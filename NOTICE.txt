CORRESPONDING SOURCE
--------------------
The complete corresponding source for this build, including every script
needed to reproduce it, is published in the GitHub repository at the commit
or tag matching this Release:

    https://github.com/Tale7/MusicLine

To rebuild from source:

    Python 3.11 (winsdk ships prebuilt wheels for this version)
    pip install -r requirements.txt
    pip install pyinstaller
    build_exe.bat          # or: pyinstaller MusicLine.spec

Third-party components and where their source can be obtained:

THIRD-PARTY SERVICES AND CONTENT
--------------------------------
Lyrics are fetched at runtime from LRCLIB, QQ Music and NetEase Cloud Music.
Translation uses Microsoft Bing, Google Translate, MyMemory, or an endpoint
that the user configures themselves. These are independent services subject
to their own terms of use; this project is not affiliated with any of them.
No API key or account credential is bundled with this binary. Baidu Translate
is not used.

Lyrics are copyrighted works. They are cached only on the local machine for
playback and are NOT distributed with this binary or with the source tree.

The application icon (MusicLineLogo.png / MusicLine.ico) is supplied by
this fork's maintainer; it is not the upstream bird logo. The upstream
copyright notice in LICENSE applies to the code, not to this icon.
